핵심 역량

2011년부터 NC에서 클라이언트 프로그래머로 일하며 AOS, 슈팅, 대전 액션, 방치형까지 장르가 다른 네 개의 프로젝트를 거쳤습니다. 그중 둘은 상용 출시했고, 최근 프로젝트에서는 팀장을 맡아 업무 분배와 일정 관리를 함께 수행했습니다.

언리얼 엔진 심화 활용

Gamebryo에서 UE4로의 엔진 컨버팅을 거쳐 UE4·UE5를 실무에서 사용해 왔습니다. Slate 기반 에디터 확장, GameFeature, LevelSequence, AnimMontage·AnimNotify, PoseAsset, SceneCapture 등 필요한 엔진 기능을 목적에 맞게 선택해 씁니다.

멀티플레이어 전투 동기화

서버와 클라이언트의 권한 분배, 동기화 구조를 설계하고 개선해 왔습니다. 입력 반응성을 위해 클라이언트가 먼저 수행하고 서버가 검증하는 구조, RPC와 Replication의 선택 기준, 상태를 BitArray로 압축해 대역폭을 줄이는 방식까지 Dedicated Server 환경에서 다뤘습니다.

크로스 플랫폼 대응

PC, Android, iOS, 닌텐도 스위치, 게임패드까지 서로 다른 입력 체계와 빌드 환경을 하나의 코드베이스에서 다뤘습니다. 입력 처리를 계층 구조로 정리해 플랫폼별 분기를 최소화했습니다.

확장을 염두에 둔 시스템 설계

당장의 구현 편의보다 프로젝트가 커졌을 때 발생할 공수를 기준으로 구조를 정합니다. 전투 로직을 별개의 모듈로 분리해 서버 검증과 리플레이에 함께 쓰는 구조를 설계하거나, 컨텐츠를 GameFeature 단위로 나눠 운영 중 ON/OFF 할 수 있게 만든 사례가 있습니다.

개발 도구 · 파이프라인 구축

NodeEditor, Dialogue Editor, 리소스 분석기 등 기획·아트가 직접 사용하는 도구를 만들어 왔습니다. Jenkins 멀티 에이전트 빌드 파이프라인과 PSO 캐시 수집 자동화처럼, 팀 전체의 반복 작업을 줄이는 일에 관심이 많습니다.

AI를 붙인 개발 워크플로

Claude Code로 방치된 BP 그래프 노드가 있는 애셋을 검색하고, 자연어로 익스포트한 뒤 C++로 일괄 변환했습니다. 손이 많이 가지만 판단이 단순한 정리 작업을 AI에 넘기는 방식으로 활용합니다.
