방문 통계

이력서 페이지(index.html)의 방문 기록입니다. 이 페이지는 검색에 노출되지 않으며, 아래 데이터는 본인 API 토큰이 있어야 표시됩니다.

연결 설정

GoatCounter API 토큰을 한 번만 등록하면 됩니다

  1. goatcounter.com에서 무료 계정을 만들고 사이트 코드를 정합니다.
  2. 이 파일 맨 아래 CODE 값을 그 사이트 코드로 바꿉니다. index.html의 CODE도 같은 값이어야 합니다.
  3. 대시보드 우측 상단의 사용자 메뉴 → API(주소는 /user/api)에서 토큰을 만듭니다. 사이트 설정이 아니라 사용자 메뉴에 있습니다.
  4. 토큰을 아래에 붙여넣습니다.

토큰은 이 브라우저의 localStorage에만 저장되며 저장소에 커밋되지 않습니다. 다른 사람이 이 주소를 열어도 데이터는 보이지 않습니다.
